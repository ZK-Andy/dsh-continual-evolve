### 问题修复

- 默认关闭自动进化接线：`autoReview: false` 时不再注册自动回合/压缩 listener，避免通用 review/planner、prompt/skill 和 local fate 意外触发。@ZK-Andy

<h3 id="en-v0.7.5">Features</h3>

### Bug Fixes

- Disabled automatic evolution wiring by default: `autoReview: false` no longer registers automatic turn/compaction listeners, preventing unexpected generic review/planner, prompt/skill, and local-fate activity. @ZK-Andy
- Corrected `autoReview: true` semantics so it enables only the dedicated Memory Agent, never the generic review, planner, or fate pipeline. @ZK-Andy
- Aligned the Memory Agent trigger gate with ZCode: direct user text must contain at least three lexical words in one text part, using CJK-aware segmentation; empty deltas, internal agents, and direct memory writes remain skipped; memory-only mode no longer adds a compaction trigger. @ZK-Andy

### Chores

- Updated `/evolve status`, `pause`, and `resume` to report and control the Memory Agent-only listener accurately. @ZK-Andy
- Synchronized the README, FAQ, design document, and implementation ADR; expanded regression coverage to 743 tests across 45 files. @ZK-Andy
