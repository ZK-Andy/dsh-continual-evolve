<h3 id="cn-v0.11.0">v0.11.0 — 架构重构：一条循环，零违标</h3>

本次为重构整理版（无新功能、无行为破坏，store 格式与审计语义不变）：

- **时刻驱动记忆提取**：per-turn 后台提取管线废除（实测烧掉 90% 直调 LLM 只换来 20% 沉淀、2% 落盘率）。专用 memory loop 只在四个低频时刻醒来——压缩、goal 连续受阻、会话收尾 drain、手动 wrapup；成功回合零 LLM 成本，日常沉淀由对话直写承担。删除 `localFate`/`fateIntervalTurns`/`reviewIntervalTurns` 配置键。
- **结构治理清零**：三个循环依赖（`auto⇄fate`、`command⇄benchmark-command`、`command⇄mount-command`）、双组装根、facade 绕过、六个超预算文件全部清偿。新架构门禁 `verify-architecture.ts` 进 run-gates：五层模型、禁环、host-API 单点边界、规模预算全部机器强制，违标白名单已清空。
- **理念归一**：`docs/design.md` 重写为"一条循环"叙事（模型提议，代码保证；对话直写为主、时刻提取为辅）；旧版三代设计史移 `docs/research/` 冷归档；`docs/coding-standard.md` 与 `docs/architecture-standard.md` 入仓，oxlint correctness 升为 error。
- **提效**：`/evolve plan`、export/import 等下沉为引擎 facade 方法；命令面纯路由化；src 约 18.5k → 16.4k 行（净 −2.1k），测试 1110 → 1020（删死路径套件、补时刻触发回归）。

升级提示：从 0.10.x 升级请移除 profile patch 中的 `reviewIntervalTurns`/`localFate`/`fateIntervalTurns`（0.11.0 不再识别）；其余零改动。

<h3 id="en-v0.11.0">v0.11.0 — Architecture refactor: one loop, zero violations</h3>

A consolidation release (no new features, no breaking behavior; store format and audit semantics unchanged):

- **Moment-driven memory extraction**: the per-turn background pipeline is gone (it burned 90% of the plugin's direct LLM calls for 20% of the sediment at a 2% apply rate). The dedicated memory loop now wakes only at four low-frequency moments — compaction, goal-blocked streaks, the session-close drain, and manual wrapup. Successful turns cost zero LLM calls; conversation writes own routine sedimentation. Removed config keys: `localFate`, `fateIntervalTurns`, `reviewIntervalTurns`.
- **Structural debt cleared**: three import cycles (`auto⇄fate`, `command⇄benchmark-command`, `command⇄mount-command`), dual composition roots, facade bypasses, and six oversized files are all resolved. A new machine gate `verify-architecture.ts` joins run-gates enforcing the five-layer model, cycle freedom, host-API single-point boundaries, and size budgets — the violation whitelist is now empty.
- **One-loop narrative**: `docs/design.md` rewritten around the single sediment→gate→store→inject→verify loop; the three-era design history moved to `docs/research/` (cold archive); `docs/coding-standard.md` and `docs/architecture-standard.md` landed; oxlint correctness raised to error.
- **Mechanics**: `/evolve plan` and export/import become engine facade methods; the command surface is a pure router; src shrinks ~18.5k → 16.4k lines (net −2.1k), tests 1110 → 1020 (dead-path suites removed, moment-trigger regressions added).

Upgrade note: when moving from 0.10.x, drop `reviewIntervalTurns` / `localFate` / `fateIntervalTurns` from your profile patch (no longer recognized in 0.11.0); everything else is unchanged.
