<h3 id="cn-v0.7.6">新功能</h3>

- （无）

### 问题修复

- 修复 v0.7.5 引入的回归：Memory Agent listener 恢复常驻注册。`autoReview` 只提供没有 `evolve/runtime.json` 时的初始默认，不再是注册开关；此前默认安装（profile 无配置）不注册任何 listener，`/evolve resume` 会被静态策略拒绝，必须手改 `cordis.patch.yml` 才能开启，装完即用失效。现在任何安装都可以直接 `/evolve resume` 开启，v2 `{enabled, paused}` 仍是唯一有效控制面。@ZK-Andy
- 保留 v0.7.5 确立的边界：自动运行仍然只有专用 Memory Agent；通用 review/planner、prompt/skill 写入与 local fate 都不可达，只能显式手动调用。`localFate` 保持默认关闭。@ZK-Andy

### 其他改动

- 移除随注册门一起作废的 `automaticEvolutionWired()` 与其测试文件，以及恒为 memory-only 的 `CommandRuntimeOptions.memoryOnly`。@ZK-Andy
- 同步 README、FAQ、设计文档与实现 ADR；回归测试规模为 742 tests / 44 files。@ZK-Andy

<h3 id="en-v0.7.6">Features</h3>

- (none)

### Bug Fixes

- Fixed a regression introduced in v0.7.5: the Memory Agent listener is registered unconditionally again. `autoReview` now only supplies the initial default when `evolve/runtime.json` does not exist yet instead of gating registration — previously a default install with no profile config registered nothing and `/evolve resume` was rejected by static policy, so turning the agent on required hand-editing `cordis.patch.yml`. Any install can now enable the agent with `/evolve resume`, and the v2 `{enabled, paused}` runtime switch remains the only effective control surface. @ZK-Andy
- Kept the boundary established in v0.7.5: the Memory Agent remains the only automatic pipeline. Generic review/planner, prompt/skill writes, and local fate stay unreachable and require explicit manual invocation. `localFate` remains off by default. @ZK-Andy

### Chores

- Removed `automaticEvolutionWired()` and its test file, which became obsolete with the registration gate, plus the now-constant `CommandRuntimeOptions.memoryOnly`. @ZK-Andy
- Synchronized the README, FAQ, design document, and implementation ADR; regression coverage is 742 tests across 44 files. @ZK-Andy
