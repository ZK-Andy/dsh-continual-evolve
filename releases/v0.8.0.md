<h3 id="en-v0.8.0">Features (all four Memory P1 items)</h3>

- Directional recall: new model tool `evolve_recall` (query/kind/scope/memory-type/limit filters, full content with version, source, and staleness signals, read-only), plus human commands `/evolve recall`, `/evolve remember <type> [scope] <text…>` (immediate single-memory write through full validation and approval), and `/evolve forget [scope] <query…>` (archives the single match, lists ambiguous queries, errors on no match) (@zhangkun) <!-- 196f29f -->
- Readable Markdown projection: every memory apply has the engine rewrite the `<store>/MEMORY.md` index plus one frontmatter fact file per entry; rollback/archive stay in sync through the same apply path, with no model-writable entry point (@zhangkun) <!-- 8e006af -->
- Memory extraction benchmark: deterministic precision/recall/duplicate/stale/noise scorer with explicit grade thresholds; the extractor prompt gains a do-not-remember exclusion list (git history, re-readable repo paths, temporary state) (@zhangkun) <!-- d12eb22 -->
- Unified extraction receipts and bounded drain: the memory phase records `noop`/`applied`/`declined` audit rows with duration/turn/search stats; only applied outcomes queue a foreground follow-up; a closing session lets in-flight extraction settle within `sessionCloseDrainMs` (default 15s) before aborting (@zhangkun) <!-- 755bbaf -->
