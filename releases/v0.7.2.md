<h3 id="en-v0.7.2">Features</h3>
- Runtime-controlled automatic review with ZCode-aligned cadence: the listener is always registered, while `autoReview` is only the initial default. `/evolve resume`, `/evolve pause`, and `/evolve status` now control and inspect v2 runtime state immediately without profile edits or a restart. <!-- f0a8af2 -->
- Incremental successful-turn snapshots and serial scheduling: `agent/turn-stopping` plus idle capture produces incremental events with seq/index cursors. Mechanical eligibility filters internal turns, direct memory writes, synthetic/model-only input, and short user text. Each session uses a serial latest-pending scheduler; failures and aborts do not advance the cursor, and agent disposal aborts the scheduler.
- Review/planner prefix-cache Route A now receives only the current incremental snapshot while preserving DSH local/project/global scopes, approvals, snapshots, rollback, and audit semantics.
- ADR: `.agents/notes/implemented/feature/2026-09-24-zcode-turn-snapshot-scheduler.md`.
