<h3 id="cn-v0.7.1">新功能</h3>

- 规划器与 review 门禁支持 prefix-cache 感知输入：检测到缓存读取证据时用结构化会话前缀（Route A），否则保持扁平轨迹（Route B），并可配置路由与字符预算。 @ZK-Andy <!-- 33607ae -->
- `evolve_delete` 支持 `ids` 批量删除：一次 refinement、一次审批，并修复合并视图中冒号字面 ID 无法删除的问题。 @ZK-Andy <!-- ca5dba6 -->
- 新增 `/evolve pause | resume | status`：聊天内暂停/恢复自动门禁并查看运行时状态；暂停时 turn-interval 与 compaction 两条门禁路径均休眠，手动操作不受影响。 @ZK-Andy <!-- d0d2262 -->
- `/evolve usage` 新增直属 LLM 精确 token 账本：记录 review / planner / wrapup / fate 的 provider input、缓存读写、output 与 total；缺失 usage 显式标记，旧 DSH 世代自动回退 total 计算。 @ZK-Andy <!-- 38d308a -->

### 问题修复

- 合并视图删除时优先匹配 `local:` / `project:` / `global:` 等字面 ID，缺失时才按作用域前缀回落，避免合法冒号 ID 无法命中。 @ZK-Andy <!-- ca5dba6 -->

### 其他改动

- 存储卫生：快照、refinements、reviews 与 token usage 各自按可配置尾部预算修剪，避免审计与历史文件无界增长。 @ZK-Andy <!-- ca5dba6 -->

<h3 id="en-v0.7.1">Features</h3>

- Prefix-cache-aware planner and review inputs: structured session prefixes are used when cache-read evidence exists (Route A), while the legacy flat trajectory remains the fallback (Route B); routing and character budgets are configurable. by @ZK-Andy <!-- 33607ae -->
- `evolve_delete` now accepts an `ids` array for batch deletion with one refinement and one approval; literal colon-prefixed IDs are also matched correctly in merged views. by @ZK-Andy <!-- ca5dba6 -->
- New `/evolve pause | resume | status` commands let users pause or resume the automatic gate and inspect its runtime state. Both turn-interval and compaction gate paths sleep while paused; manual operations remain available. by @ZK-Andy <!-- d0d2262 -->
- `/evolve usage` now includes an exact direct-call token ledger for review, planner, wrap-up, and fate calls, with provider input, cache read/write, output, and total buckets. Missing samples stay explicit, and older DSH generations use a compatible total fallback. by @ZK-Andy <!-- 38d308a -->

### Bug Fixes

- Merged-view deletion now prefers literal IDs such as `local:`, `project:`, or `global:` and only falls back to scope-prefix stripping when no literal match exists. by @ZK-Andy <!-- ca5dba6 -->

### Chores

- Storage hygiene: snapshots, refinements, reviews, and token usage now use independent configurable tail budgets so history and audit files cannot grow without bound. by @ZK-Andy <!-- ca5dba6 -->
