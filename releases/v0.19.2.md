本版是一次**减法 + 收口**：移除合成四臂评测与外锚（`evolve_eval_run` 工具与 `evals/runs` 生成链一并下线，离线召回评测与基线保留），并补上两处写门禁与两处门禁兼容性修复。945 测试 / 77 文件、20 道门禁与 CI 全绿。

<h3 id="cn-v0.19.2">移除与停用</h3>

- **合成四臂评测与外锚下线（`1f258a2`，@ZK-Andy）**：`services/eval-runner.ts`、四臂执行链、`evolve_eval_run` 工具、`compare.md` 产物、休眠提示词补充的调用面全部删除——这条链产出的数字没有任何读者动作，属于往库里合法排污。保留：离线召回评测 `npm run eval:recall` 与 `evals/` 基线（月度 CI 守基线，不再卡发版）。同时新增两道锁：架构标准不变量「新机制必须声明回边与读者」，ADR 模板强制 `## Feedback edge` 小节。理由见 ADR `kill-dead-eval-loop`。
- **评测门径维持冻结（`333debc`，@ZK-Andy）**：合成数作废、p95 口径线过期不重议，待生产账本反证再议。

<h3 id="cn-v0.19.2">问题修复</h3>

- **提级可移植性门禁（`971eba7`，@ZK-Andy）**：记忆的标题/钩子/正文/不适用条件任一含源工作区绝对路径，进全局即 fail-closed 并点名字段——提级是两个工作区之间的搬运，源路径进全局等于把私有上下文广播出去。判词落在提级唯一漏斗上，手动 `move-to-global` 与自动提级两路同吃。
- **归档与隔离行拒绝原地改写（`4523131`，@ZK-Andy）**：`update` 只改 `active` 行。此前撞上已归档 id 会原地改写历史快照，而提案仍返回成功——写了一份永不进入注入的副本还自称更新了。现在：判词门点明状态与归档原因；`MEMORIES.updateSql` 追加 `AND status = 'active'` 作机械兜底；`updateRow` 返回变更行数，0 行不再被读成落地。
- **freshness 门兼容 runner 的 markdown 列表 commit 行（`4261e59`，@ZK-Andy）**：回填产物把 commit 写在列表头，门禁认不出，误报数据过期。
- **tier 门豁免 `evals/runs` 机器回填数据（`4866ae0`，@ZK-Andy）**：机器生成的回填数据不再按人工编辑口径计 diff。

<h3 id="en-v0.19.2">Removals</h3>

- **The synthetic four-arm eval loop and its anchors are gone (`1f258a2`, @ZK-Andy)**: `services/eval-runner.ts`, the four-arm execution chain, the `evolve_eval_run` tool, `compare.md` output, and the dormant prompt-supplement call surface are all removed — the numbers that chain produced drove no reader action, which made them legal pollution of the store. Kept: the offline recall eval (`npm run eval:recall`) and the `evals/` baselines (monthly CI guards the baseline; it no longer gates releases). Two locks land with the removal: the architecture invariant "every new mechanism declares its feedback edge and readers", and a mandatory `## Feedback edge` section in the ADR template. Rationale: ADR `kill-dead-eval-loop`.
- **The eval-gate verdict stays frozen (`333debc`, @ZK-Andy)**: synthetic numbers voided, the old p95 line is not reopened; revisit only against production-ledger counter-evidence.

<h3 id="en-v0.19.2">Bug Fixes</h3>

- **Promotion portability gate (`971eba7`, @ZK-Andy)**: a memory whose title, hook, body, or caveat carries the source workspace's absolute path is refused (fail-closed) when it would enter the global partition, with the offending field named. Promotion moves knowledge between workspaces; a source path in the global partition broadcasts private context. The verdict sits on the single promotion funnel, so the manual `move-to-global` and the automatic path both hit it.
- **Archived and quarantined rows refuse in-place rewrites (`4523131`, @ZK-Andy)**: `update` now only rewrites `active` rows. Hitting an archived id used to rewrite the historical snapshot while the proposal still reported success — an edit to a copy that never re-enters injection, reported as an update. Now: a gate names the status and the archive reason; `MEMORIES.updateSql` carries `AND status = 'active'` as the mechanical backstop; `updateRow` returns the changed-row count, so zero rows can no longer be read as a landed edit.
- **Freshness gate reads the runner's markdown commit list (`4261e59`, @ZK-Andy)**: backfilled artifacts put their commit on a list header the gate failed to parse, so it reported the data as stale.
- **Tier gate exempts machine-written `evals/runs` data (`4866ae0`, @ZK-Andy)**: backfilled machine data no longer counts as a human edit when the diff is scored.

<h3 id="en-v0.19.2">Other Changes</h3>

- Dormant prompt-store coverage filled in (`90c2286`, @ZK-Andy): readback, isolation scenario, constants, try-finally, tmp cleanup.
- First-run artifacts backfilled (`b0740a2`, @ZK-Andy): `evals/runs` landed in the store as input for later measurement decisions.
- Workflow and handoff baseline readings brought up to date (`f397e3f`, @ZK-Andy).
