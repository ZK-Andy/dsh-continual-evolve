<h3 id="cn-v0.12.1">v0.12.1 — 官方插件管理内置只读记忆卡片</h3>

- **只读记忆卡片**：插件在官方插件管理的本 bundle 页面（`plugins.bundle.config` slot）挂一张只读投影——最近服务过的工作区、各自记忆条目/索引行数、索引漂移警告（未索引文件与索引失联文件）。事实源永远是 `.evolve/memory/` 里的文件：卡片无编辑路径、无缓存，刷新即重读磁盘。
- **安全围栏**：host 侧两条 GET-only 路由（`/dsh-continual-evolve/api/v1/*`）；`memory?root=` 只接受本进程真实服务过会话的工作区（进程内 LRU 白名单，不落盘），不能探测任意路径。
- **优雅降级**：宿主缺 `webServer` 服务或 `plugins.bundle.config` slot 时卡片自动缺席，核心记忆注入不受影响；client bundle 为手写工厂（不依赖宿主 UI primitives，react 不可达时自禁用）。
- **读时验证指南**（v0.12.0 发版后合入）：when_to_save 指南新增读取侧纪律——引用记忆前发现与现实不符，当场修正或删除文件与索引行（ADR `2026-10-04-read-time-verification`）。
- **新配置键**：`memoryCard.enabled`（默认 `true`）。
- 决策与边界见 ADR `2026-10-04-plugin-management-card`。

### 升级提示

- 更新后重启 DSH profile 即生效；卡片在官方插件管理的插件页面查看——本进程服务过至少一个工作区会话后显示数据，此前显示引导文案。
- `memoryIndex.*` 配置与行为无任何变化。

<h3 id="en-v0.12.1">v0.12.1 — Read-only memory card in the official plugin manager</h3>

- **Read-only memory card**: the plugin mounts a read-only projection on its own page in the official plugin manager (the `plugins.bundle.config` slot) — recently served workspaces, per-workspace entry/index counts, and index-drift warnings (unindexed files, index rows whose file is gone). The source of truth remains the files under `.evolve/memory/`: the card has no edit path, no cache, and refetches from disk on refresh.
- **Security fence**: two GET-only host routes (`/dsh-continual-evolve/api/v1/*`); the `memory?root=` parameter only accepts workspace roots the running process has actually served (an in-process LRU allowlist, never persisted) — no arbitrary-path probing.
- **Graceful degradation**: hosts without the `webServer` service or the `plugins.bundle.config` slot simply show no card; the core memory injection is unaffected. The client bundle is a hand-written factory (no host UI primitives dependency; self-disables when react is unreachable).
- **Read-time verification guide** (landed after v0.12.0): the when_to_save guide gains a read-side rule — when a memory contradicts reality on use, fix or delete the file and its index row on the spot (ADR `2026-10-04-read-time-verification`).
- **New config key**: `memoryCard.enabled` (default `true`).
- Decision and boundaries: ADR `2026-10-04-plugin-management-card`.

### Upgrade notes

- Restart your DSH profile after updating; open the plugin's page in the official plugin manager to see the card — it shows data once this process has served at least one workspace session.
- `memoryIndex.*` configuration and behavior are unchanged.
