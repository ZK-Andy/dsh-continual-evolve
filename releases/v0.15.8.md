<h3 id="cn-v0.15.8">v0.15.8 — 提取补上便宜预检门：设计一直是两次</h3>

评审轨的 gate→evolve 早就是两次调用，提取还是一次贵调用包办——本版补上缺的那一半。起因是真凭实据：两条版本细节被提取误收成记忆，而评审 gate 当时正好抖动挂掉，没拦住。

### 新功能

- **提取便宜预检门**（@ZK-Andy，`d283d9c`）：贵调用（manifest 50 + 8 个全文候选 + 4 万字符增量）之前，先用增量前 4KB + 归属三测跑一次小 verdict（512 token 上限）。拒了直接按 `model-skip (cheap-gate)` 消费游标，不烧全量 prompt；门不清不楚（解析失败/调用挂了）透传给贵调用——最差退化成老单调用，永不 stall。贵用量与门用量分 `usage` / `cheap_usage` 两列记账，旧库 ALTER 迁移。
- **归属三测守两条管线前门**（@ZK-Andy，`414ca90`）：提取 prompt + 评审 gate/evolve rubric 共用主语/去名/归属三测——版本细节从源头不进记忆，误入的判 quarantine（隐藏不删）。门/改写调用失败记错误原文进 verdict 行，不记秃码（此前秃码掩盖了约 50% 的 gate 抖动）。
- 测试 319 → 328 例（提取预检门：拒跳过/批透传/透传降级/迁移/解析 + 失败原文记账），typecheck/lint/文档门禁/`check:pack` 全绿；覆盖率门禁全文件达标。

### 升级提示

- 无配置变更、无破坏性变更；新列 `cheap_usage` 旧库打开即迁，无需手动迁移。
- dotnet-desktop 是 npm 实体拷贝：更新到 0.15.8 并重启 profile 后，**请硬刷新 GUI 页面**（Ctrl+Shift+R）。
- 验收：账本 `extraction_log` 新增 `cheap_usage` 列——`SELECT skip_reason FROM extraction_log WHERE skip_reason LIKE 'model-skip (cheap-gate)%' LIMIT 5` 应有行；试运行 dry-run 仍开，评审无落盘变化。

<h3 id="en-v0.15.8">v0.15.8 — cheap pre-gate for extraction: the design was always two calls</h3>

The review track has been two calls (gate → evolve) all along; extraction ran one expensive call per run — this release adds the missing half. Triggered by hard evidence: two version-scoped entries were extracted as memories while the review gate happened to be flapping and missed them.

### Features

- **Extraction cheap pre-gate** (@ZK-Andy, `d283d9c`): before the expensive call (50-line manifest + 8 full-body candidates + 40k-char increment), a small verdict runs on the increment head (4KB) plus the ownership triple-test (512-token cap). Refusals consume the cursor as a `model-skip (cheap-gate)` without burning the full prompt; an unclear gate (parse failure / call error) fails open to the full call — worst case degrades to the old single-call behavior, never to a stall. Full and gate usages ledger in separate `usage` / `cheap_usage` columns, old stores migrate via ALTER.
- **Ownership triple-test guards both tracks** (@ZK-Andy, `414ca90`): the extraction prompt and the review gate/evolve rubrics share one subject/name-stripped/home test set — version specifics never enter as memories, mis-homed rows verdict quarantine (hidden, never deleted). Gate/leg failures ledger the error text in the verdict row instead of a bare code (bare codes had hidden ~50% gate flapping).
- Tests 319 → 328 (pre-gate: refuse-skip/approve-pass/fail-open/migration/parsing + failure-text accounting); typecheck, lint, docs gates, and `check:pack` all green; per-file coverage floors held.

### Upgrade notes

- No config changes, no breaking changes; the new `cheap_usage` column migrates on open, no manual migration needed.
- dotnet-desktop resolves the plugin as an npm copy: after updating to 0.15.8 and restarting the profile, **hard-refresh the GUI page** (Ctrl+Shift+R).
- Acceptance: the `extraction_log` ledger carries a new `cheap_usage` column — `SELECT skip_reason FROM extraction_log WHERE skip_reason LIKE 'model-skip (cheap-gate)%' LIMIT 5` should return rows; trial dry-run still on, no review landing changes.
