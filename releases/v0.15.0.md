<h3 id="cn-v0.15.0">v0.15.0 — SQLite 单库：代码唯一写者 + 提案制提取</h3>

这是存储形态的一次重设计：全部记忆从"工作区里的 md 文件 + 模型原生读写"迁移进**一个中央数据库** `~/.dsh/evolve/memory.db`（SQLite，按工作区路径行分区）。10-04 版"文件即真相"的唯一硬理由——模型直写 home 目录会触发写围栏弹窗——在本版写路径重构后不复存在；按"机械门禁优先于文件透明性"的既有判据，supersede 之。决策依据（五路调研 + SQLite spike 全绿）见 `docs/research/memory-update-retirement-survey-2026-10-06.md`，取舍全文见 ADR `2026-10-06-sqlite-single-store`。

### 新功能

- **中央单库**（@ZK-Andy）：`node:sqlite`（Node ≥ 22.5，桌面宿主 EnsureNode 运行时自带）单文件存储——memories（STRICT 表，type/status 枚举 CHECK、body ≤64KB 约束即门禁）+ FTS5 trigram 中文全文索引（查询恒带工作区过滤）+ 提取游标 + 快照账本，WAL 模式，零新依赖。运行时缺 `node:sqlite` 时插件整体降级为无操作 + 控制台告警，宿主不受影响。
- **`memory_write` / `memory_read` 双工具**（@ZK-Andy）：显式"记住……"/"忘掉……"走 `memory_write`（create/update/delete），每条提案过代码门禁（id 规范含 CJK hash 兜底、type 枚举、feedback 必带 **Why:**/**How to apply:**、v1 移植的 secret 正则筛查、64KB 上限）后在一个事务内原子落盘，任何一条被拒整批回滚；`memory_read` 按 id 取正文、按关键词检索——注入索引只有钩子，正文按需取。宿主缺工具服务时降级为"告诉用户"措辞，注入不受影响。
- **提案制提取**（@ZK-Andy）：插件唯一的后台自动化，全程 `extraction_log` 记账可对账。轮级触发（`agent/turn-stopping`）+ 空闲去抖（默认 10 分钟，`memoryIndex.debounceMin` 可配，0 = 每轮即跑）+ 单飞行合并突发（运行中新轮只刷新边界）；`compaction/start` 与会话收尾强制 flush。一次运行 = 读游标后的轨迹增量 → 机械跳过判定（内部 agent / 空增量 / 无真实用户文本 ≥3 词 CJK-aware / 当轮已有显式写入，全部记账）→ FTS 取相似既有记忆喂一次 LLM 调用 → 闭集提案（create/update/delete）过同一套门禁落盘 → 推进游标 → 巡检随跑。**失败与被拒不推游标**，下次触发重试。
- **回滚靠账本**（@ZK-Andy）：每次变更内嵌 before/after 全文快照，undo = 取 before 重写；终极兜底是会话轨迹本身（`source_seqs` 溯源可回放）。
- **无损迁移**（@ZK-Andy）：首次接触某工作区时，旧版 `.evolve/memory/*.md` 自动导入该工作区分区（缺失字段就地合成，不丢），原目录改名 `memory-imported-<日期>/` 保留——不删不丢。
- **提取边界收窄**（@ZK-Andy）：`4a1e57d` 的 user/feedback/reference 三类型 + "换仓库还有用才进记忆、决策走 ADR"判据随本版一并生效。

### 变更

- **卡片改查库**（@ZK-Andy）：工作区列表 = 库内工作区分区（目录已删的分区失联不显示不阻塞）；内容预览按 id 取（原按文件名路由作废）；"索引漂移警告"升级为**巡检异常**——每次提取应用后随跑巡检（孤儿 FTS 行清除、active 行 secret 扫描），命中行 `quarantined` 隐藏不删、卡片显形。`workspace-catalog.ts` / `known-workspaces.ts` 退役。
- **主会话指南瘦身**（@ZK-Andy）：when_to_save 分类学整体移入提取 prompt；主会话只留三行（库位置 / 显式写入走工具 / 其余沉淀有专职流程）。
- **架构规范修订**（@ZK-Andy）："零后台自动化"不变量修订为"提取轨是唯一获准的常驻自动化"，护栏（去抖/合并/记账/门禁）入宪。

### 升级提示

- dotnet-desktop 是 npm 实体拷贝：更新到 0.15.0 并重启 profile 后**请硬刷新 GUI 页面**（Ctrl+Shift+R），避免浏览器继续用旧的 client bundle。
- 验收：①注入索引正常出现 ②对模型说"记住……"走 `memory_write` 落库 ③卡片工作区列表与内容预览正常 ④`~/.dsh/evolve/memory.db` 生成、旧 `.evolve/memory/` 目录改名 `memory-imported-<日期>/`。
- 新配置键：`memoryIndex.extraction`（默认 `true`，关闭则只保留注入 + 显式工具）、`memoryIndex.debounceMin`（默认 `10`）；`memoryIndex.enabled/guide/order/maxChars`、`memoryCard.enabled` 行为不变。
- 旧版记忆不迁移也可以：不删除任何数据，随时可手动 salvage `memory-imported-<日期>/` 里的文件。

<h3 id="en-v0.15.0">v0.15.0 — SQLite single store: the code is the sole writer, plus proposal-based extraction</h3>

A storage redesign: every memory moves from "markdown files in the workspace, read and written natively by the model" into **one central database**, `~/.dsh/evolve/memory.db` (SQLite, rows partitioned by workspace path). The only hard reason for the 10-04 "files are the store" shape — model writes to home triggering the write-fence prompt — disappears once the model no longer writes storage directly, so this version supersedes it on the existing "mechanical gates over file transparency" criterion. Decision basis (five-way survey + a green SQLite spike): `docs/research/memory-update-retirement-survey-2026-10-06.md`; full rationale: ADR `2026-10-06-sqlite-single-store`.

### Features

- **Central single store** (@ZK-Andy): one `node:sqlite` file (Node ≥ 22.5, shipped by the desktop host's EnsureNode runtime) holding memories (STRICT table; type/status CHECKs and a 64KB body cap as literal gates), an FTS5 trigram index (Chinese verified; queries always workspace-scoped), extraction cursors, and a snapshot ledger — WAL mode, zero new dependencies. Without `node:sqlite` the plugin degrades to a no-op with a console warning.
- **`memory_write` / `memory_read` tools** (@ZK-Andy): explicit "remember …" / "forget …" goes through `memory_write` (create/update/delete); every proposal passes the code gates (id shape with a CJK hash fallback, type enum, the feedback **Why:**/**How to apply:** contract, secret regexes carried over from v1, the 64KB cap) inside one transaction — any rejection rolls the whole batch back. `memory_read` fetches bodies by id and searches by keyword; the injected index carries hooks only. Hosts without the tools service degrade to "tell the user" phrasing, injection unaffected.
- **Proposal-based extraction** (@ZK-Andy): the plugin's only background automation, fully audited in `extraction_log`. Turn-level trigger (`agent/turn-stopping`) + an idle debounce (default 10 min, `memoryIndex.debounceMin`, 0 = every turn) + single-flight burst coalescing; `compaction/start` and session close flush. One run = read the trajectory increment past the cursor → mechanical eligibility (internal agents / empty increments / no real user prose ≥3 CJK-aware words / a turn that already had an explicit `memory_write` — all skipped AND ledgered) → FTS-similar candidates into one LLM call → a closed-set proposal (create/update/delete) through the same gates → advance the cursor → patrol rides along. **Failures and rejections never advance the cursor.**
- **Rollback is a ledger** (@ZK-Andy): every mutation embeds full before/after snapshots; undo means rewriting the `before` values. The ultimate safety net is the session trajectory itself (`source_seqs` provenance, replayable).
- **Lossless migration** (@ZK-Andy): on first contact with a workspace, legacy `.evolve/memory/*.md` files are imported into that workspace's partition (missing fields synthesized in place — nothing dropped) and the directory is renamed aside as `memory-imported-<date>/`.
- **Extraction boundary narrowed** (@ZK-Andy): the user/feedback/reference taxonomy and the "useful across repositories or it belongs to the repo's ADR route" judgment from `4a1e57d` ship with this version.

### Changes

- **Card queries the store** (@ZK-Andy): the workspace list is the store's partitions (vanished directories drop out of the list without blocking); content previews are keyed by id (the by-filename route is retired); the "index drift warning" becomes a **patrol report** — a hygiene pass rides every applied extraction (orphan FTS rows dropped, active rows scanned for secrets; hits are quarantined — hidden, never deleted — and surfaced on the card). `workspace-catalog.ts` / `known-workspaces.ts` retired.
- **Slim main-session guide** (@ZK-Andy): the when-to-save taxonomy moved into the extraction prompt; the main session keeps three lines.
- **Architecture standard amended** (@ZK-Andy): the "zero background automation" invariant now reads "extraction is the only sanctioned background automation", with its guardrails (debounce, coalescing, ledger, gates) written in.

### Upgrade notes

- dotnet-desktop ships an npm copy: after updating to 0.15.0 and restarting the profile, **hard-refresh the GUI page** (Ctrl+Shift+R) so the browser drops the old client bundle.
- Acceptance: ① the injected index appears ② "remember …" lands via `memory_write` ③ the card lists workspaces and previews bodies ④ `~/.dsh/evolve/memory.db` exists and the old `.evolve/memory/` directory is renamed `memory-imported-<date>/`.
- New config keys: `memoryIndex.extraction` (default `true`; off keeps injection + explicit tools only) and `memoryIndex.debounceMin` (default `10`). `memoryIndex.enabled/guide/order/maxChars` and `memoryCard.enabled` behave as before.
