### Bug Fixes

- Fixed direct plugin LLM calls in dotnet desktop / opencode-go profiles dropping the host Agent `sessionId`. Memory extraction, review, planning, and wrap-up now forward `GenerateOptions.sessionId`, preventing provider `MissingSessionID` failures that silently stopped background work. @ZK-Andy
- Corrected the installation guidance to restart the DSH profile actually in use (web or desktop), rather than mentioning only `dsh web`. @ZK-Andy

### Chores

- Added a direct-call session-routing regression test proving that the host session identity reaches `ctx.llm.stream`; updated the baseline to 738 tests / 44 files.
- Synchronized the README, design document, FAQ, and bug-fix ADR: `.agents/notes/implemented/bug-fix/2026-09-24-direct-llm-session-routing.md`.
