<h3 id="cn-v0.7.0">新功能</h3>

- 类型化单条记忆：每条 memory 必须带召回类型（`user | feedback | project | reference`），踩坑（`feedback`）必须含 Why + How to apply；`evolve_add`/`evolve_update` 新增 `memoryType` 参数。 @ZK-Andy <!-- 851189c -->
- 项目级跨会话 store：`HarnessScope` 新增 `project`（`evolve/projects/<slug-hash>/`，合并顺序 global < project < local），tool 与 `/evolve` 全面支持 `project` 作用域，project 写与 global 同审批门。 @ZK-Andy <!-- 851189c -->
- 目录索引升级：按 `rankEntries(relevanceQuery)` 排序截断，memory 行带类型钩子（`[memory:type:id]`）；小 store 的 memory 不再被冗余判断吞掉。 @ZK-Andy <!-- 851189c -->

### 问题修复

- 冻结测试 fixture 时钟，消除毫秒抖动导致的 tie-order 断言 flake（CI 上 `formatPromptEntriesSection` bounded-entries 用例）。 @ZK-Andy <!-- 5630f5a -->

### 其他改动

- 发版流程：DSH 式双语 GitHub Release notes（`scripts/draft-release-notes.sh` 草稿脚本 + 流程卡更新）。 @ZK-Andy <!-- 469ae40 -->
- 跟进 0.1.7-rc.1 宿主世代（cordis 4.0.4）；零契约漂移，600 测试全绿。 @ZK-Andy <!-- dc1f87e -->

<h3 id="en-v0.7.0">Features</h3>

- Typed one-fact memories: every memory entry carries a recall type (`user | feedback | project | reference`); pitfalls (`feedback`) must include Why + How to apply. New `memoryType` parameter on `evolve_add`/`evolve_update`. by @ZK-Andy <!-- 851189c -->
- Per-project cross-session store: new `project` scope (`evolve/projects/<slug-hash>/`, merge order global < project < local); tools and `/evolve` accept the `project` scope, and project writes share the global approval gate. by @ZK-Andy <!-- 851189c -->
- Directory index upgrade: relevance-ordered truncation via `rankEntries(relevanceQuery)`, type hooks on memory lines (`[memory:type:id]`); memories in small stores are no longer swallowed by the redundancy check. by @ZK-Andy <!-- 851189c -->

### Bug Fixes

- Freeze the test fixture clock to kill millisecond-jitter flakes in tie-order assertions (the `formatPromptEntriesSection` bounded-entries case on CI). by @ZK-Andy <!-- 5630f5a -->
