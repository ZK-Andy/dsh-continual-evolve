<h3 id="cn-v0.14.0">v0.14.0 — 卡片对齐 ZCode 记忆选项卡 + 官方双语元数据</h3>

- **双语显示名/描述（根除拼串）**：新增包根 `locale/en.json` + `locale/zh.json`（宿主 `readPluginMeta` 的正式通道）——插件管理页与内置插件列表里，显示名（工作区记忆 / Workspace Memory）与描述随 DSH 语言切换，不再是包名，也不再是"中文 / 英文"单条拼串（普通字符串宿主原样渲染，两种语言都显示整串还带字面 `/`）；package.json 描述改回纯英文。
- **卡片形态对齐市场**：默认收起 + 头部整行可点（名称 + 一行说明 + 旋转 chevron，primitives 图标缺失降级 `▾`）+ hover/展开框态（dshmarket SettingsCard 同款 token：`bg-layer-3` 底、`label-dimmed` 边、展开换 `bg-layer-2`）；样式为一次性注入的 `<style>`（宿主 CSS-module 同机制），类名前缀 `dce-`，token 全带字面回退色。
- **卡片内容对齐 ZCode 设置 → 记忆选项卡**：工作区 chips 选择器（显示目录名，LRU 上限 8）+ 文件搜索框 + 文件行带相对更新时间（刚刚/N 分钟前/今天/昨天/日期，活动语言经 `localeTag` 字典键）+ 点击行内展开文件内容预览（`<pre>` 滚动，5 MiB 上限，已删除/超大/读取失败三态）；索引漂移警告（失联/未入索引）保留——本插件观察项的刻意超集。
- **Host 只读扩展**：快照条目新增 `updatedAt`（mtimeMs）；新增第三条 GET-only 路由 `/api/v1/memory/file`——同一工作区白名单围栏，只接受记忆目录内纯 `.md` 文件名（禁路径分隔符/穿越，basename + resolve 双校验），超 `MEMORY_FILE_PREVIEW_LIMIT`（5 MiB，与 ZCode 预览上限一致）答 413 不读体，stat→read→stat 检出读期间变更以 `changed` 上报。
- 测试 66 → 80 全绿；老宿主降级路径不变（缺 slot/primitives/locale 时卡片退化为同主题裸元素，注入不受影响）。决策见 ADR `2026-10-05-zcode-memory-viewer-card`；宿主 locale 机制踩坑记入 `docs/FAQ.md` #7。

<h3 id="en-v0.14.0">v0.14.0 — Card aligned with ZCode's memory viewer + official locale metadata</h3>

- **Localized display name / description (concatenation eradicated)**: ships package-root `locale/en.json` + `locale/zh.json` (the host's `readPluginMeta` channel) — the plugin manager and built-in inventory now switch the display name (Workspace Memory / 工作区记忆) and description with the DSH language, instead of the package name and a slash-concatenated bilingual string (plain strings render verbatim in both languages with a literal `/`); the npm description is English-only again.
- **Market-parity card form**: collapsed by default with a full-row header toggle (name + one-liner + rotating chevron, falling back to `▾` without primitives) and hover/open frame states on dshmarket's SettingsCard tokens; one injected stylesheet (the host's CSS-module mechanism), `dce-` prefixed classes, every token with a literal color fallback.
- **Content aligned with ZCode's Settings memory viewer**: workspace chips (directory-name labels, LRU bound 8), a file search box, per-file relative updated times (just now / N min ago / today / yesterday / date, active language via the `localeTag` dictionary key), and click-to-preview file bodies (scrolling `<pre>`, 5 MiB cap, deleted / too-large / failed states); index-drift warnings stay as a deliberate superset.
- **Read-only host extension**: snapshot entries carry `updatedAt`; a third GET-only route `/api/v1/memory/file` serves one file's body behind the same workspace allowlist fence — plain `.md` names inside the memory directory only (separators and traversal rejected), 413 without a body beyond the 5 MiB cap, and a `changed` flag when the file moved between stat and read.
- Tests 66 → 80, all green; old-host degradation paths unchanged. Decision: ADR `2026-10-05-zcode-memory-viewer-card`; the locale mechanism is recorded as FAQ #7.
