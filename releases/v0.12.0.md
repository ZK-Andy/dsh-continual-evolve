<h3 id="cn-v0.12.0">v0.12.0 — 终极收敛：完全对齐 ZCode</h3>

**这是一个破坏性重定义版**：插件不再是"持续自进化"机制集，而是一个最小的工作区记忆注入器——与 ZCode 的持久记忆完全同构。

- **单一 store**：`<工作区根>/.evolve/memory/`——`MEMORY.md` 索引 + 一事一文的 markdown 文件（frontmatter：name / description / metadata.type = user | feedback | project | reference）。文件就是 store，没有 JSON 引擎。
- **开局注入**：一个 system-prompt section（order 400）注入索引正文 + 记忆目录绝对路径 + when_to_save 指南；会话内逐字节冻结守 prompt cache；超预算按整行截断并提示直接读目录；空 store 零 token。
- **原生读写**：模型用 Read/Write/Edit 直接操作记忆文件并维护索引。bootstrap 首次使用自动建目录；git 仓库自动把 `.evolve/` 追加进工作区 `.gitignore`（非 git 工作区不碰任何文件）。
- **全部拆除**：`evolve_*` 模型工具（list/recall/add/update/delete/rollback）、`/evolve` 命令面（21 条子命令）、global/project/local 三作用域、治理机器（快照/版本/回滚/审批弹窗/审计/用量记账）、后台提取流水线、benchmark 闭环、技能物化与热挂载。src 70 → 3 文件，测试 58 → 3（32 例）。
- **配置只剩**：`memoryIndex.{enabled,guide,order,maxChars}`（true/true/400/6000）。其余全部配置键随机制删除。
- **无治理的设计决定**：单人场景下坏记忆就是工作区里一个可见文件，删掉它就是退役。决策与证据链见仓库 ADR `2026-10-04-zcode-alignment-teardown`（supersede `zcode-parity-boundary`）。

### 升级提示（破坏性）

- 从 ≤0.11.0 升级等于换了一个产品：所有 `evolve_*` 工具与 `/evolve` 命令消失，旧配置键（`baseDir`/`autoReview`/`reviewModel`/`requireGlobalApproval` 等）不再识别——请清理 profile patch，只保留 `memoryIndex.*`。
- 旧 store `~/.dsh/evolve/` 不再读写、不做迁移；确认不需要历史数据后可整体删除。
- 升级后重启 DSH profile 即生效：新会话开场会出现 `<memories>` 注入与 `# 持久记忆` 指南，对模型说"记住……"即可沉淀。

<h3 id="en-v0.12.0">v0.12.0 — Full alignment with ZCode</h3>

**Breaking redefinition**: the plugin is no longer a self-evolution machinery set — it is a minimal workspace-memory injector, structurally identical to ZCode's persistent memory.

- **One store**: `<workspace-root>/.evolve/memory/` — a `MEMORY.md` index plus one markdown file per fact (frontmatter: name / description / metadata.type = user | feedback | project | reference). The files are the store; there is no JSON engine.
- **Session-start injection**: a single system-prompt section (order 400) injects the index content, the absolute store path, and the when_to_save guide; frozen per session to protect the prompt cache; whole-line truncated over budget with a read-the-directory hint; zero tokens on an empty store.
- **Native read/write**: the model reads, writes, and edits memory files with its native tools and maintains the index. Bootstrap creates the store on first use; in a git workspace it appends `.evolve/` to the workspace `.gitignore` (non-git workspaces are left untouched).
- **Everything else removed**: the `evolve_*` model tools, the `/evolve` command face (21 subcommands), the global/project/local scopes, the governance machinery (snapshots, versioning, rollback, approval popups, audit, usage accounting), the background extraction pipeline, the benchmark loop, and skill materialization/hot-mounting. src 70 → 3 files, tests 58 → 3 (32 tests).
- **Configuration reduced to**: `memoryIndex.{enabled,guide,order,maxChars}` (true/true/400/6000). All other config keys died with their mechanisms.

### Upgrade notes (breaking)

- Upgrading from ≤0.11.0 is a product swap: all `evolve_*` tools and `/evolve` commands are gone; legacy config keys are no longer recognized — keep only `memoryIndex.*` in your profile patch.
- The old store `~/.dsh/evolve/` is no longer read or written and is not migrated; delete it once you no longer need the history.
- Restart your DSH profile after updating: the first session shows the `<memories>` injection and the `# 持久记忆` guide; just tell the model "remember …" to sediment a fact.
