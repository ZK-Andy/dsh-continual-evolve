<h3 id="en-v0.10.5">Features (memory content injection + a low-friction write path)</h3>

- **Passive read: memory content injected at session start** — a new `evolve:memory-index` system-prompt section (order 400) puts memory CONTENT (not just an id/title directory) in front of the model, because the store lives outside the workspace sandbox where the read tool cannot reach it. Ranked `project > feedback > user > reference` under a hard 6k-character budget: overflow degrades to one-line index rows, then to a fold counter (`evolve_recall` reads the rest). The section is **frozen per session** (built once per `agent.id`, reused byte-for-byte), so the system prompt stays stable and prompt-cache reads keep hitting — a memory written mid-session appears in the next session (@zhangkun) <!-- 36520a5 -->
- **The when_to_save guide rides along** — the full "when to save / how to use / body structure" text for all four recall types (including "confirmation is a quieter signal than correction — watch for it" and "the description is the future relevance hook"), injected even with an empty store, since a fresh install would otherwise never learn to write. Configured via `memoryIndex.{enabled,guide,order,maxChars}`; with the guide off and an empty store, injection costs zero tokens (@zhangkun) <!-- 36520a5 -->
- **De-duplication** — memories no longer appear in the entry directory (one fact, one home), and injection-usage accounting moved with them (@zhangkun) <!-- 36520a5 -->

### Behavior changes

- **Slash commands pruned 25 → 21** — `remember` / `forget` / `recall` are gone (the v2 guide already moves reading, writing, and forgetting into the conversation, backed by the `evolve_add` / `evolve_delete` / `evolve_recall` tools), along with `demote` (an alias of `archive <id> global`). The call came from a full session-log measurement (1,058 log files spanning 08-13 → 10-01: 302 invocations, zero in October, 12 subcommands never invoked) — but **zero calls is not grounds for deletion**: every emergency valve (`export` / `import` / `pause` / `resume` / `status` / `log` / `archive` / `unarchive` / `unmount`) stays, and so does `consolidate` (the only batch-hygiene path) (@zhangkun) <!-- 4de9ba8 -->
- **Layered help** — `/evolve` and `/evolve help` list the 11 everyday subcommands; `/evolve help all` expands the advanced half (consolidate / failures / log / export / import / mount / goal / benchmark / usage). Less cognitive load by layering, not by removing capability (@zhangkun) <!-- 4de9ba8 -->

- Handoff governance landed: the three-file HANDOFF family (rolling window + action area + cold archive), a workspace-root anchor, and the structure gate ported to TypeScript in-repo and wired into CI/pre-push (@zhangkun) <!-- c758023 66d843a -->

- Bilingual README / design / FAQ synced: rewritten injection shape, four new `memoryIndex` config rows, and a new FAQ entry on system-prompt section facts (the empty 1–499 order range, name tiebreaks, fail-loud duplicate names) (@zhangkun) <!-- 0f71dd9 bcc6553 -->
