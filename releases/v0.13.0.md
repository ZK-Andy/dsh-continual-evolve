<h3 id="cn-v0.13.0">v0.13.0 — 市场同款记忆卡片（含双语跟随）</h3>

- **市场同款外观**：卡片跟随 dshmarket 接线——宿主主题 token（卡片底、边框、圆角 12px）、`Button` 原语刷新按钮（`outline/sm`），老宿主降级为同主题裸元素，设置对话框永不白屏。
- **双语跟随系统语言**：全部卡片文案进 `zh/en` 字典（`ctx.locale.register/bind`），DSH 切英文卡片即英文；技术错误码保留语言中立的 `HTTP xxx` 形。
- **根除 `[object Object]`**：文件行改 children 传参（`createElement("li", …, strong(file), " — description")`），此前 `element + 字符串` 把文件名压成 `[object Object]`。
- **双语包描述**：`package.json description` 改为"中文 / English"，插件列表行不再满屏英文；`dsh.client.inject` 补齐市场三件套（locale / ui-settings / ui-theme）。
- host 侧（只读 API、白名单围栏）零改动；`memoryCard.enabled` 与降级语义不变。决策见 ADR `2026-10-05-market-parity-card`。

### 升级提示

- dotnet-desktop 是 npm 实体拷贝：更新插件到 0.13.0 后重启 profile，在官方插件管理本插件页查看——中文语言全中文，英文语言全英文。
- `memoryIndex.*` 配置与行为无任何变化。

<h3 id="en-v0.13.0">v0.13.0 — Market-parity memory card (bilingual)</h3>

- **Market-parity look**: the card follows the dshmarket wiring — host theme tokens (card surface, border, 12px radius), the `Button` primitive for refresh (`outline/sm`), and a downgrade to themed plain elements on old hosts so the settings dialog never blanks.
- **Bilingual, follows the system language**: all card copy lives in `zh/en` dictionaries (`ctx.locale.register/bind`); switching DSH to English turns the whole card English. Technical error codes stay language-neutral (`HTTP xxx`).
- **`[object Object]` eradicated**: file rows now pass children (`createElement("li", …, strong(file), " — description")`) instead of `element + string`, which had coerced the filename into `[object Object]`.
- **Bilingual package description**: `package.json description` is now "Chinese / English"; `dsh.client.inject` gains the market trio (locale / ui-settings / ui-theme).
- Host side (read-only API, allowlist fence) untouched; `memoryCard.enabled` and downgrade semantics unchanged. Decision: ADR `2026-10-05-market-parity-card`.

### Upgrade notes

- dotnet-desktop installs an npm copy: update the plugin to 0.13.0, restart the profile, and open the plugin's page in the official plugin manager — fully Chinese under the Chinese locale, fully English under English.
- `memoryIndex.*` configuration and behavior are unchanged.
