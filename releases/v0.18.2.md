### 问题修复
- **卡片投影合并全局记忆（`83f00ba`，@ZK-Andy）**：记忆被提级后，来源行归档、全局副本又落在卡片从不列出的全局分区，于是这条记忆在卡片上彻底消失。现在记忆投影照技能既有形状合并 L0 分区：每条带 `scope`（项目/全局），卡片显示「全局」徽标；隔离行同样标出所属分区；内容预览沿用「本地优先、缺失回落全局」的读语义。

### Bug Fixes
- **The card now merges the global memory partition (`83f00ba`, @ZK-Andy)**: once a memory was promoted, its source row was archived while the global copy lived in a partition the card never listed — so the memory vanished from the card entirely. The memory projection now merges the L0 partition the same way skills already did: every row carries `scope` (project/global) and the card renders a "global" badge; quarantined rows name their partition too, and the body preview keeps the local-first read semantics.
