# 会话模式契约（session-modes）

> 会话开场声明类型（用户指定或 agent 复述确认）；模式切换必须显式声明。边界有争议时停下询问，不默认扩权。

| 模式 | 许可范围 | 禁区 | 典型产出 |
|---|---|---|---|
| **讨论** | 决策记录（ADR/HANDOFF）的写入；仓库内只读检视 | src/test/scripts/系统配置零写入；不提议开工 | 结论、拍板、落档 |
| **调研** | 外部资源与仓库只读；本地工具安装需逐次授权 | 任何写入（含文档，除非用户要求落档） | 调研报告 |
| **实现** | 按 [feature-flow](feature-flow.md) 动代码：src/test/scripts/docs | 越出既定方案范围的顺手改动 | 提交 + 测试 + ADR |
| **发布** | 按 [release-flow](release-flow.md) 执行 | 计划外的代码变更 | 新版本 + 核验记录 |

## 通用边界

- 写工作区之外的文件（用户 home、系统目录）一律先说明目标路径再动手。
- 「讨论中顺手改了」不算授权；文档类决策记录除外（讨论型会话的本职产出）。
