# 会话收尾检查单（session-close）

> 会话结束/阶段性告一段落时执行；全部完成才算收尾（教训：未记录的提交曾导致下个会话误读决策）。

1. **提交对账**：`git log` 本会话全部提交 vs HANDOFF 最新记录——每条提交必须能对应到交接条目。
2. **决策落档**：本轮讨论的拍板结论是否已进 ADR / HANDOFF？没有则补。
3. **待办对账**：HANDOFF 待办区增删（新立事项写清受影响面与前置研究点）。
4. **未推送提醒**：本地领先 origin 的提交数如实告知用户；是否推送由用户定或按既定惯例（本项目惯例：完成即推）。
5. **工作树确认**：`git status` 干净；仓库内不应有未跟踪文件（HANDOFF/OBSERVATION 在工作区根，仓库外）。
6. **交接条目**：HANDOFF 顶部追加本会话记录——日期｜类型｜一句话结论｜关键提交哈希｜遗留事项。
