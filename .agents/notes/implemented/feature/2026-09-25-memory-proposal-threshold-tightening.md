# Agent Note: 记忆提案口径收紧（已修复一次性排障不再提案）

Status: implemented

## Problem

Memory Agent 对"已解决的问题"过度提案：2026-09-25 当晚，fcitx5 输入法修法（`GTK_IM_MODULE=fcitx` 落盘、重启验证通过、已闭环）被提案为 global user 记忆。用户拒绝，理由是已修复、低复发、无需记录。既有 "Do not remember" 排除了一次性调试轨迹，但没点名"已修复且无复发证据的排障结论"，模型把"刚解决"误当成"值得沉淀"。

## Decision

- `MEMORY_AGENT_SYSTEM_PROMPT` 的 "Do not remember" 追加：已应用且已闭环、无复发证据的排障结论不再提案（落在盘上的修复状态本身就是记录）。
- 粒度示例追加 reject 锚点：今晚被拒的 fcitx5 提案原文级示例（one-off applied fix → reject），模型仿照示例而非仅抽象规则。
- 提示词仍在 3000 字符预算内（实测 2883）。
- 质量契约测试钉死两处新表述；行为级变更配套回归断言。

## Alternatives considered

- **保持现状、靠人工拒绝**：每次误判都要弹一次审批打断用户，拒绝。审批是兜底，不是口径。
- **把阈值改成"复发 ≥2 次才记"硬数字**：单次但高价值的偏好/规则（如中文正文要求）会被误杀，拒绝。当前写法是"无复发证据的已修复结论"才排除，偏好与规则不受影响。
- **local 暂存代替直接 no-op**：local 也会进后续 wrapup/门禁视野，等于换个地方打扰，拒绝。一锤定音的 no-op 最干净。
- **删掉示例、只加抽象规则**：既有测试注释已确认模型仿照示例 specificity，纯规则弱于示例锚点，拒绝。

## Consequences

- 同类一次性排障（修完即闭环、无复发证据）直接 no-op，不再弹窗。
- 偏好、项目规则、可复用教训的提案标准不变。
- 测试基线 1032 例（54 文件）全绿；提示词预算测试继续看守 3000 上限。
