# Agent Note: 指南新增读时验证（引用前不符即修删）

Status: implemented

## Problem

终极收敛后记忆维护只有写入侧规则（"状态变化时更新"），触发条件是对话中目击到状态变化；读取侧没有纪律——模型引用一条与现实不符的坏记忆时，没有任何指南要求它当场修正或删除。坏记忆由此存活并被反复引用（ZCode 的指南同样只有写入侧，退役完全依赖用户手删）。

## Decision

在 `MEMORY_GUIDE_RULES` 的"如何维护"节新增一条：**引用记忆前若发现与现实不符，当场修正或删除该文件与索引行——坏记忆的危害随引用扩散，退役不留给用户。** 同步 `docs/design.md` 指南清单与指南测试。纯指南改动，零新机制，退役闭环在记忆层内部完成。

## Alternatives considered

- **晋升式退役（多次验证的 durable 记忆自动晋升进工作区 AGENTS.md/docs）**：被用户否决。① bootstrap 主动把 `.evolve/` 写进 .gitignore，设计明确"记忆不进版本库"；晋升绕过这道墙，个人偏好进 diff/PR/commit 历史。② 本项目是公开 GitHub 仓库，记忆含用户纠错反馈，自动晋升等于把私人反馈发布到公网——性质从污染升级为外发。记忆升层改为"模型建议、用户拍板"，不设自动通道。
- **给退役加 TTL/衰减调度**：与终极收敛拍板相悖（治理机器为单人场景付费），读时验证以零机制覆盖同一需求，拒绝。

## Consequences

- 指南体积增加约两行（6k 注入预算内）；模型获得读取侧退役纪律，坏记忆的第一发现人是模型而非用户。
- dotnet-desktop 装的是 npm 实体拷贝，本改动须随下次发版才在用户日常环境生效。
