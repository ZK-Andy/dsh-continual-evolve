# Agent Note: P7 后残留收敛 + 脚本层 TS 化

Status: implemented

## Problem

P7（表现层收敛）落地后 `verify-src-budgets` 仍报 10 条 WARN（单函数软预算 80 行），另有两处硬性残留：`SKILL_GENERATED_MARKER` 文案仍写已退役的 `skill_write`；`services/memory-apply.ts` 自带 `LEDGER_SQL` 与 `data/ledger.ts` 的 `prepareLedgerStmts().ledger` 逐字重复，SQL 漏进 services 层。脚本层另有三处残尾：`record-browser-gif` 技能死亡（批量搬运进仓后零引用、证据链笔记不存在、依赖的 `browser-control` 未安装）；`change-scope.sh` / `draft-release-notes.sh` 仍是 shell（门禁脚本 2026-09-25 已 TS 化）；`setup-hooks.sh` 仅 8 行；`pre-push` 自带一套 base 推导与 `change-scope.sh` 重复。用户拍板：干净整洁优先，A（src 12 项）+ B（脚本 5 项）全做。

## Decision

Phase A 用四种手段，不引入新抽象：Extract Method（主力）、Strategy（`create/update/delete` 分支提为具名函数，保留原 `if` 调度）、Factory（沿用 `createXxx` 风格收敛 `store.ts` 装配）、Bundle 复用（`LedgerStmts` 整包传参）。`openMemoryStore` 拆分为类内模块函数 + `applySkillProposals` 体搬进 `services/skill-apply.ts` 作 `applySkillBatch`（与 `applyPromptBatch` 对齐）+ patrol 体搬进新建 `data/patrol.ts`（文件操作走回调参数，沿用 `quarantineSecrets` 先例，避免 data→surfaces 反向依赖）。

H1 采用稳定前缀方案：渲染串 `skill_write`→`evolve_write`；两处托管判定（`removeSkillFile`、`reconcileSkillFiles` 孤儿清扫）从 `includes(整串)` 改为 `includes("generated by dsh-continual-evolve")` 并提 `isManagedSkillFile(content)` helper——新旧 marker 共有该前缀，旧标记孤儿文件仍被识别，一次 patrol 即收敛，无僵尸文件。回归测试锁：旧 marker 文件仍判托管 + patrol 后全等新渲染。

Phase B：删 `record-browser-gif/` 整目录；`change-scope.sh`→`change-scope.ts`（配 vitest 回归，补 `package.json` 的 `change-scope` 入口——三个 dsh-* 技能文案调的是该入口但一直缺失）；`draft-release-notes.sh`→TS（`release-flow.md` 引用同步）；删 `setup-hooks.sh`（命令收进 AGENTS.md 一行）；`pre-push` 去重瘦身但保留 bash（git hook 必须是可执行文件，tsx shebang 引入提交时不可用的脆弱性）。`encode_gif.py` 随技能删除，不转。

## Alternatives considered

- **三类 applier 跨文件统一为通用模板**：三类语义已分叉（`move-to-global`、`scope` 各不相同），硬统一是耦合不是去重，拒绝。
- **H1 守卫用 LEGACY 常量兼容旧串**：留一个永久包袱，稳定前缀零包袱且未来改措辞免疫，拒绝。
- **H1 不改渲染串**：旧名永留用户可见文件，违背本次初衷，拒绝。
- **`setup-hooks.sh` 转 TS**：8 行配模块是仪式，删并收文档，拒绝。
- **hooks 本体转 TS**：git hook 可执行约束 + tsx 可用性假设，风险大于整洁收益，拒绝（但去重）。
- **删 marker 机制本身**：巡检的托管判定依赖它，删等于拆自愈，拒绝。

## Consequences

- `verify-src-budgets` WARN 10→0；文件硬预算不变（新增仅 `data/patrol.ts` 约 45 行）。
- `SKILL_GENERATED_MARKER` 改后首次 patrol 重写全部 active 技能文件（`skillFilesReconciled` 一次性跳涨），旧标记孤儿一次清掉；测试全符号化引用，自动跟随。
- `record-browser-gif` 删除后 `.agents/skills/` 仅剩 `dsh-*`（上游原样）+ `evolve_*`（自创），命名空间干净。
- `change-scope` npm 入口补上后，三个 dsh-* 技能文案里的 `pnpm run change-scope` 首次真正可跑。
